# ES6 Basics

## Description
This project covers the fundamentals of JavaScript ES6, including `const`, `let`, block scoping, and modern syntax.

## Requirements
* Executed on Ubuntu 20.04 LTS using Node.js 12.x.x
* All files end with a new line
* Code evaluated using ESLint

## Tasks
* **0-constants.js**: Refactor code to use `const` and `let` instead of `var`.

# ES6 Promises

This repository contains tasks for the **ES6 Promises** project, part of the Backend Curriculum at **Holberton School**. The goal of this project is to learn how to handle asynchronous operations using JavaScript (ES6) Promises, `async/await`, `try/catch` blocks, and error handling.

## 📋 Requirements & Environment

- **Node.js**: `v12.x.x` or higher
- **Package Manager**: `npm`
- **OS**: Ubuntu 18.04 LTS or compatible environment

## 🛠️ Setup

Install project dependencies by running the following command in the project root directory:

```bash
npm install

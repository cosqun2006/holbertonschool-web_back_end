# ES6 Data Manipulation

This repository contains tasks for the **ES6 Data Manipulation** project, part of the Backend Curriculum at **Holberton School**. The objective is to practice data manipulation using modern JavaScript (ES6) features such as array methods (`map`, `filter`, `reduce`), Typed Arrays, and data structures like `Set` and `Map`.

## 📋 Requirements & Environment

- **Node.js**: `v12.x.x` or higher
- **Package Manager**: `npm`
- **OS**: Ubuntu 18.04 LTS or compatible environment

## 🛠️ Setup

Install project dependencies by running the following command in the project root directory:

```bash
npm install
